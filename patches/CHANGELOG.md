# 版本更新说明

每个小节对应一个 `harmony.N` 版本。发布时 `harmony_release.yml` 把对应小节原样写进 Release 正文的「## 本次变更」，
应用内更新的弹窗（补丁 0008 起）也只显示这一节，所以请写给使用者看的、简短的要点，每行一条，以 `- ` 开头。

发布前先在这里补上新版本的小节；找不到对应小节时 Release 正文会写「见下方补丁列表」。

## harmony.9

- 检查更新改为先读本仓库 `repo` 分支上的 Release 索引（raw.githubusercontent.com），读不到再请求 GitHub 接口；不再因为 GitHub 匿名接口「每个 IP 每小时 60 次」的配额被用完而报 HTTP 403。

## harmony.8

- 关闭「自动检查更新」后，设置页的「检查更新」仍可手动检查、下载并安装新版本；没有新版本时会提示「已是最新」。
- 新版本弹窗里的更新说明改为可滚动，不再把按钮挤出屏幕；下载按钮由「自动更新」改名为「立即更新」。
- 更新弹窗只显示 Release 正文的「本次变更」一节，而不是补丁清单和安装说明。
- 「应用内下载」开关不再因关闭自动检查而变灰。
- 启动时自动删除已经安装完成的更新安装包，不再占用缓存空间；「查看更新日志」指向本仓库的 Release 页。

## harmony.7

- 两个下载前台服务的通知与 Mihon / Anikku 鸿蒙版统一：显示速度、百分比和确定型进度条，在线源缓存通知展开可见正在缓存的「番剧 - 集」。

## harmony.6

- 在线源缓存服务改为媒体播放类型并循环播放静音音轨，解决退后台几秒后进程被卓易通冻结、下载停摆的问题。

## harmony.5

- 第一次开始在线源缓存时请求「忽略电池优化」；缓存期间持有 WakeLock。

## harmony.4

- 在线源（HTTP / m3u8）缓存新增前台服务和进度通知（带「暂停全部」），缓存不再因退后台而停止。

## harmony.3

- 包名改为 `me.him188.ani.harmony`，可与官方版共存，并绕过卓易通对已知包名的签名校验。

## harmony.2

- 应用内更新改为检查本仓库的 Release，不再被官方更新服务器推送无法安装的官方 APK。

## harmony.1

- BT 下载前台服务每次都真正调用 `startForeground()`，修复进入后台后下载停止的问题。
